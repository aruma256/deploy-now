# 積立シミュレーション

外部ライブラリ・API・ビルド処理なしの静的サイト。ロリポップ！デプロイナウの `static` に対応。

## ローカル確認

Node.js 22 以上で実行します。依存インストールは不要です。

```sh
cd tsumitate
npm run dev
```

http://localhost:4173 を開きます。サーバーはスマホからのLANアクセスにも対応するため `0.0.0.0:4173` で待ち受けます。

```sh
npm test
```

## 計算仕様

- 金額は内部計算も万円。表示のみ小数1桁へ丸めます。
- 投資実質年率 = 運用利回り − 年間コスト率。
- 実効月利 = `(1 + 年率 / 100) ** (1 / 12) - 1`。
- 投資は毎月利息を反映後、月末に積立額を追加します。
- 預金は初期残高を別途複利運用し、積立資金の引落しはしません。
- コスト差は、コストなしの投資評価額との差（複利への影響を含む）。
- 税金、インフレ、個別売買手数料は計算しません。
- 有効な入力を変更するたびに即座に計算し、条件をlocalStorageへ保存し、次回アクセス時に復元します。異なるオリジン（ローカルと本番等）間では共有されません。

年間コスト率の初期値は0.05775%、手入力は小数5桁まで。上下ボタン・上下キーは次の0.1%刻みへ移動します（0.05775%から上は0.1%、下は0.0%）。保存済みの条件は優先され、初期値に戻すと新しい初期値が適用されます。グラフは各年の5区分の積み上げ棒グラフ。棒の高さが総資産です。利回りと預金金利は0%以上、年間コスト率は運用利回り以下に制限します。範囲外や入力途中の値では結果・保存値を更新せず、理由を表示します。旧保存値が新しい制約を満たさない場合は初期値に戻します。

金額入力は1万円刻みの整数。計算結果は引き続き小数1桁で表示します。棒の下から預金元本・預金利息・初期投資・毎月の積立分・投資利益の順に積み上げます。
